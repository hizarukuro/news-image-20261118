A one-image newspaper front page summing up Wednesday 18 November 2026:
44 stories from 6 continents — the Iranian drone attack on a US air base
in Kuwait, Xi greeting Trump as APEC opens in Shenzhen, the COP31 split
over a fossil-fuel phase-out, Russia's overnight drone barrage on Ukraine,
Israeli tanks crossing the Gaza truce line, Bangladesh wage protests,
Voyager 1 reaching one light-day from Earth, and GTA VI going on sale at
midnight — plus 36 one-line briefs, a world map of where it happened, and
a date check that keeps out stories first reported on 17 November. Every
drawing is original flat vector-style art, typeset for this page.

## Run it

```sh
python3 main.py
```

This copies `entry.png` into `$MAKEFUN_OUTPUT_DIR` (or an `output`
directory when that variable is unset) as `entry.png`, byte-identical
every time. The program uses only the Python 3.13 standard library.
