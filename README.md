A one-image newspaper front page that sums up Wednesday 18 November
2026, drawn as an atlas: **One Day · One Map**. This is a second,
full-day edition — it waits for the whole of Wednesday to finish, then
tells the day in place. A large world map sits at the centre of the
page with numbered pins for every illustrated story and gold dots for
the briefs, so the shape of the day is visible at a glance: Xi greeting
Trump on the tarmac in Shenzhen as APEC opens, Bahrain and Kuwait
intercepting Iran's drones over the Gulf, Voyager 1 reaching one
light-day from Earth, 141 drones fired at Ukraine overnight, a €45bn
EU loan proposed for Kyiv, UK inflation at a one-year high, Cyclone
Akvan turning toward Odisha, and 35 one-line briefs from Manila to the
Cook Islands — 48 stories across 6 continents, with a numbers band, a
continent tally, and a date check that keeps out anything first
reported on Tuesday or earlier. Every drawing is original flat
vector-style art made for this page. Entered on make.fun (referral
code c23ct4sn).

## Run it

```sh
python3 main.py
```

`main.py` copies the finished front page (`entry.png`, stored beside
it in this repository) into the output directory, byte for byte. Set
`MAKEFUN_OUTPUT_DIR` to choose the destination; without it, the image
is written to a folder named `output`. The program uses only the
Python standard library and produces identical output on every run.
